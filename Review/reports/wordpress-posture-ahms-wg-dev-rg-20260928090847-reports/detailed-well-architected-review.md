## 4. Reliability

**Score 0% · Coverage 53% · Red**

No reliability control passed. The architecture is a single B1 App Service worker on a non-zone-redundant plan, running a Burstable-tier MySQL server with high availability disabled, seven-day backup retention, and no geo-redundant backup. Always On is off, so the site cold-starts after idle; there is no health check path, no auto-heal rule, no autoscale rule, and no deployment slot, which means every deployment is an in-place restart of the only instance. There are no availability tests and no alerts, so an outage would be discovered by a user rather than by the platform. Eight further controls — including recovery objectives, restore testing, and dependency failure behaviour — could not be decided because no business requirements or test results were supplied. This configuration is a reasonable development sandbox; it cannot meet a production availability commitment in its current form.

## 5. Security

**Score 39% · Coverage 75% · Red**

Security has the best evidence coverage in the review at 75%, and the platform-level design is genuinely strong: every data service — MySQL, Redis, Key Vault, and storage — is reachable only through a private endpoint with public network access disabled, the application authenticates to all of them with a user-assigned managed identity, TLS 1.2 is the enforced minimum throughout, and Key Vault uses RBAC with soft delete enabled. That good work is undermined at the two ends of the request path. At the edge, the Front Door WAF policy is in Detection mode with no managed rule sets attached at all, so it observes attacks and blocks nothing. At the origin, the WordPress administrator password is stored in plain text in an App Service connection string as part of a shared bootstrap account, phpMyAdmin is enabled with no admin-path protection, the SCM deployment endpoint accepts traffic from any address, and Key Vault has purge protection disabled. Four controls carry severity 5. These are configuration changes rather than architectural ones, which makes them unusually cheap to fix relative to the risk they carry.
